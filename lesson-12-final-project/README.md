# Урок 12. Итоговый проект: REST API «Библиотека»

## Цель урока
Объединить все полученные знания (Spring Boot, JPA, REST, Docker, профили) в одном завершенном проекте, который можно добавить в портфолио.

---

## Теория

### 1. Архитектура проекта
Наш итоговый проект будет представлять собой REST API для управления библиотекой. 
Он будет состоять из следующих слоев:
* **Model (Entity):** Классы `Book` (книга) и `Reader` (читатель).
* **Repository:** Интерфейсы для работы с базой данных.
* **Service:** Бизнес-логика (выдача книги, возврат).
* **Controller:** Обработка HTTP-запросов.
* **Exception Handling:** Глобальная обработка ошибок.
* **Docker:** Упаковка приложения и базы данных в контейнеры.

### 2. Что должно уметь приложение
1. **Управление книгами:** Добавление, просмотр всех книг, просмотр одной книги.
2. **Управление читателями:** Добавление, просмотр всех читателей.
3. **Выдача книги:** Позволяет выдать книгу читателю. Если книга уже выдана, возвращает ошибку 400.
4. **Возврат книги:** Позволяет вернуть книгу в библиотеку.

### 3. Схема базы данных
У нас будет две основные таблицы:
* `books` (id, title, author, is_available)
* `readers` (id, name)

### 4. Использование знаний
* **Spring Data JPA:** Для работы с базой данных.
* **REST:** Для создания эндпоинтов (GET, POST, PUT).
* **Обработка ошибок:** Свои исключения и `@RestControllerAdvice`.
* **Docker:** Для запуска всего стека (Spring Boot + PostgreSQL) одной командой.
