# Шпаргалка по IntelliJ IDEA

Этот файл содержит полезные горячие клавиши и лайфхаки, которые ускоряют работу в IDE.

## 1. Генерация кода (Live Templates)
Напечатайте эти сокращения в редакторе кода и нажмите `Tab`:
* `psvm` -> `public static void main(String[] args)`
* `sout` -> `System.out.println()`
* `soutv` -> `System.out.println("variable = " + variable)`
* `fori` -> цикл `for (int i = 0; i < ; i++)`
* `iter` -> цикл `for-each` для массива или коллекции
* `log` -> создание логгера SLF4J (очень полезно в бэкенде)

## 2. Основные горячие клавиши (Windows/Linux)
*(На macOS замените `Ctrl` на `Cmd`, а `Alt` на `Option`)*

### Навигация
* `Shift + Shift` — найти файл, класс или действие (Search Everywhere).
* `Ctrl + N` — найти класс.
* `Ctrl + Shift + N` — найти файл.
* `Ctrl + B` (или `Ctrl + Click`) — перейти к определению класса или метода.
* `Alt + Left` / `Alt + Right` — навигация назад/вперед по истории переходов.

### Редактирование
* `Alt + Enter` — «умное» действие (показать предложения по исправлению ошибки).
* `Ctrl + D` — дублировать текущую строку.
* `Ctrl + Y` — удалить текущую строку.
* `Ctrl + /` — закомментировать/раскомментировать строку.
* `Ctrl + Shift + /` — многострочный комментарий.
* `Ctrl + Alt + L` — отформатировать код (привести к стандартному стилю).
* `Shift + F6` — переименовать переменную, метод или класс (безопасный рефакторинг).

### Генерация
* `Alt + Insert` (или `Alt + Ins`) — сгенерировать код (конструкторы, геттеры, сеттеры, `toString`, `equals` и `hashCode`).
* `Ctrl + O` — переопределить метод родительского класса.
* `Ctrl + I` — реализовать метод из интерфейса.

### Запуск и отладка
* `Shift + F10` — запустить последнюю конфигурацию.
* `Shift + F9` — запустить в режиме отладки (Debug).
* `F8` — шаг с обходом (Step Over).
* `F7` — шаг с заходом внутрь метода (Step Into).
* `Alt + F9` — запустить до курсора.
* `F9` — продолжить выполнение.

## 3. Полезные фишки
* **Мультикурсор:** Зажмите `Alt` и кликайте в разные места, чтобы печатать сразу в нескольких местах.
* **Встроенный терминал:** `Alt + F12` (в Linux может конфликтовать с системой, тогда просто кликните на вкладку Terminal внизу).
* **Локальная история:** Если вы случайно удалили код и сохранили файл, нажмите правой кнопкой мыши -> `Local History` -> `Show History`. IDEA хранит историю изменений каждого файла, даже если вы не коммитили в Git.
* **Автоимпорт:** Если класс подчеркнут красным, нажмите `Alt + Enter` и выберите `Import class`.
