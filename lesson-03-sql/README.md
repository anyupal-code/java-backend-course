# Урок 3. SQL и реляционные базы данных

## Цель урока
Понять, как устроены реляционные базы данных, научиться писать базовые SQL-запросы и подготовить PostgreSQL для дальнейшей работы.

---

## Теория

### 1. Зачем нужна база данных?
В базовом курсе мы хранили данные в `List` или `Map`. Но если программа выключится, данные исчезнут. Чтобы сохранить их навсегда, используется база данных (БД).

Реляционная БД хранит данные в виде таблиц (как в Excel). 
* **Строка (row)** — одна запись (например, один пользователь).
* **Колонка (column)** — характеристика (например, имя, возраст).
* **Таблица (table)** — набор строк с одинаковыми колонками.

### 2. Установка PostgreSQL
Мы будем использовать PostgreSQL — одну из самых популярных и надежных баз данных.

В Fedora (Linux) установка выполняется так:

~~~bash
sudo dnf install postgresql-server postgresql-contrib
sudo postgresql-setup --initdb
sudo systemctl start postgresql
sudo systemctl enable postgresql
~~~

*(Для Windows/macOS скачайте установщик с официального сайта postgresql.org).*

После установки нужно создать пользователя и базу для нашего проекта. Зайдите в консоль PostgreSQL под суперпользователем:

~~~bash
sudo -u postgres psql
~~~

И выполните команды (не забудьте точку с запятой в конце):

~~~sql
CREATE USER myuser WITH PASSWORD 'mypassword';
CREATE DATABASE mydb OWNER myuser;
\q
~~~

Теперь у нас есть пользователь `myuser`, пароль `mypassword` и база данных `mydb`.

### 3. Основы SQL
SQL (Structured Query Language) — язык запросов к базе данных. 

**Создание таблицы:**
~~~sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT
);
~~~
* `SERIAL` — автоинкрементное поле (1, 2, 3...).
* `PRIMARY KEY` — уникальный идентификатор строки.
* `NOT NULL` — запрещает пустые значения.

**Вставка данных:**
~~~sql
INSERT INTO users (name, age) VALUES ('Иван', 25);
~~~

**Выборка данных (SELECT):**
~~~sql
-- Все данные
SELECT * FROM users;

-- С условием (WHERE)
SELECT * FROM users WHERE age > 26;
~~~

**Обновление данных (UPDATE):**
~~~sql
UPDATE users SET age = 26 WHERE name = 'Иван';
~~~

**Удаление данных (DELETE):**
~~~sql
DELETE FROM users WHERE name = 'Мария';
~~~

### 4. Связи между таблицами (JOIN)
В реальных проектах данные редко лежат в одной таблице. Для получения данных из двух таблиц используется `JOIN`:

~~~sql
SELECT users.name, orders.product_name
FROM users
JOIN orders ON users.id = orders.user_id;
~~~

## Практика

В этом уроке мы подготовили SQL-скрипты. Они лежат в папке `src/main/resources/db/scripts/`.
Запускать их нужно через терминал. 

**Пошаговая инструкция:**

1. Откройте терминал и подключитесь к вашей базе данных (мы создавали её в теории):

   ~~~bash
   psql -U myuser -d mydb
   ~~~

2. Внутри консоли PostgreSQL (приглашение `mydb=#`) выполните скрипты по очереди, используя команду `\i` (include):

   ~~~sql
   \i src/main/resources/db/scripts/01_create_tables.sql
   \i src/main/resources/db/scripts/02_insert_data.sql
   \i src/main/resources/db/scripts/03_queries.sql
   ~~~

3. Чтобы выйти из консоли PostgreSQL, введите:
   ~~~sql
   \q
   ~~~

### Альтернативный способ запуска Maven в IDEA
Хотя терминал полезен для понимания того, как всё работает «под капотом», в повседневной работе вы будете делать это прямо в IDE.
1. В правой панели IDEA откройте вкладку **Maven**.
2. Раскройте `Lifecycle`.
3. Дважды кликните по `clean`, а затем по `package` (или выделите их с зажатым `Ctrl` и нажмите кнопку запуска).
4. IDEA выполнит команду и покажет результат в отдельном окне.

Теперь ваша база данных наполнена данными. Переходите к [Заданиям](TASKS.md) для закрепления материала.
